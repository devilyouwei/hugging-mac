# Decision 3.0

## Purpose

`vllm-sr/d3` makes structured decisions from text, images, and videos using
choice, noul, and score questions.

## Support

- Variant: `edge` (default)
- Runtimes: `pytorch` (default), `coreai`
- Capability: `decision-making`
- Devices: PyTorch CPU; Apple Silicon macOS CPU or automatic Core AI placement
- Core AI status: experimental conversion candidate

## Prepare resources

Install the SDK's `d3` extra. Register D3 and explicitly download its original
weights with `sdk.resources.download_source("vllm-sr/d3")`. An existing local
checkpoint can be supplied through `source_path` instead. Managed downloads
share tokenizer, media processor, and host runtime files across both runtimes.

For Core AI, call `sdk.resources.convert("vllm-sr/d3", ArtifactFormat.COREAI)`
in the isolated conversion environment, then load with `runtime="coreai"`.
Conversion exports both decision and vision stages and supports explicit overwrite.
A complete existing converted bundle can be supplied through `artifact_path`.
When using managed storage, pass the same `model_home` for preparation and loading.
The existing Hub Core AI export is not interchangeable with this dynamic bundle.

## Example

```python
import asyncio

from hugging_mac_sdk import ModelSdk, ReusePolicy
from hugging_mac_sdk.capabilities import DecisionMaking
from hugging_mac_sdk.models.d3 import register_d3
from hugging_mac_sdk.schemas.decision import DecisionRequest


async def main() -> None:
    sdk = ModelSdk()
    register_d3(sdk.registry)
    await sdk.resources.download_source("vllm-sr/d3")
    async with await sdk.acquire(
        "vllm-sr/d3",
        variant="edge",
        runtime="pytorch",
        device="cpu",
        reuse=ReusePolicy.DEDICATED,
    ) as handle:
        response = await handle.require(DecisionMaking).decide(
            DecisionRequest(
                state="The customer was charged twice.",
                questions={
                    "route": {
                        "type": "choice",
                        "instructions": "Which team should handle this?",
                        "criteria": {"billing": "Payments", "shipping": "Delivery"},
                    }
                },
            )
        )
        print(response.answers)


asyncio.run(main())
```

## Notes and limits

The current dynamic candidate has a known confidence-parity failure and is not
approved for publication. Offline SDK tests do not establish native numerical
accuracy. The original PyTorch runtime preserves the upstream weights and processing.
The Core AI runtime executes both neural stages in Core AI; media preparation
runs on the CPU.
Images accept `ImageInput` paths or encoded bytes; videos accept local paths
or `DecisionVideoFrames` containing pre-sampled frames. D3 interprets these frames
at its upstream sampling rate of two frames per second.
Requests are serialized per instance. Cancellation waits for native work before
releasing the session. Responses include runtime information and measured time.

## Decision contract

The shared capability exposes `decision_support()` so callers can inspect limits
before sending requests. Answers are typed: inspect `answer.type`, then read
`answer.choice`, `answer.noul`, or `answer.error`. Token counts use
`response.usage.input_tokens`. A malformed or unsupported question returns a
`DecisionError` without discarding other valid questions in the request.
D3 supports `choice`, `noul` (including false/true descriptions), and `score`;
choice allows up to 255 labels and score allows 2–10 ordered JSON descriptions.
